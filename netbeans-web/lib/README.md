# Library Folder

This folder should contain the required JAR files for the project.

## Required JARs:

Download these files and place them in this folder:

1. mysql-connector-java-8.0.33.jar
2. gson-2.10.1.jar
3. HikariCP-5.0.1.jar
4. slf4j-api-2.0.7.jar
5. slf4j-simple-2.0.7.jar
6. jbcrypt-0.4.jar
7. jjwt-api-0.11.5.jar (optional - for JWT)
8. jjwt-impl-0.11.5.jar (optional - for JWT)
9. jjwt-jackson-0.11.5.jar (optional - for JWT)

See `DEPENDENCIES.md` in parent folder for download links.

## Current Status:

This folder is currently empty. Please download and add the JAR files before building the project.
